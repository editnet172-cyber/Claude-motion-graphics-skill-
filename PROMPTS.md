# Commercial Ad Prompt Library (Copy & Paste into Claude Code)

Use these tested prompts with `SKILL.md` loaded in your project to generate complete 1080p/60fps motion graphics ads in one shot.

## 1. The Flagship 8-Scene SaaS Product Launch Ad (16:9)
```text
Make a 27-second 1080p 60fps SaaS motion graphics ad using SKILL.md for [Brand Name].
Follow the full 8-scene commercial storyboard:
- Scene 1: Atmospheric hook asking "What if [Product] could do [Outcome]?"
- Scene 2: Focus-shift arrow triad ("No [Pain 1]. No [Pain 2]. Just [Solution].")
- Scene 3: Glowing hero badge reveal
- Scene 4: Dark glass UI simulation showing prompt input, 4 green checkmark steps, and live timeline output
- Scene 5: 2-row Bento Grid showing 8 core features with floating 3D spheres
- Scene 6: 3-card 3D perspective product showcase with price tag [$49] and "Add to Cart" button
- Scene 7: Fast-rewind frame scrubber ("Every single frame")
- Scene 8: Product badge + [$49] pill + creator handle [@yourhandle] + pulsing CTA button.
Run the QA validation script before finishing.
```

## 2. Viral Vertical Reel / TikTok Kinetic Ad (9:16)
```text
Create a 15-second vertical 9:16 (1080x1920 at 60fps) kinetic typography and glass UI Reel using SKILL.md for [App Name].
Include safe-zone padding (180px top/bottom), snappy spring physics, 3D floating spheres, a live UI card reveal, and a pulsing "Comment [KEYWORD]" CTA pill at the end.
```

## 3. E-Commerce Product Drop Commercial (1:1 or 16:9)

Create a 20-second 1080p product promo video using SKILL.md for [Product Name] priced at [$199].
Feature a 3-card frosted glass carousel, kinetic typography badges ("Smooth. Sharp. Premium."), animated chart comparison, and an interactive "Add to Cart" spring pop animation.
